# russian-construction-companies-analysis
Финансовый и географический анализ российских строительных компаний на основе данных БФО с использованием Python, GeoPandas и Яндекс DataLens. Анализ строительных компаний с ОКВЭД 41.20. Проект сделан в рамках учебного задания.

Проект собирает бухгалтерскую отчётность российских малых и средних компаний, рассчитывает финансовые показатели и готовит таблицы и графики для анализа строительного рынка.

**Публичный дашборд:** [отчёт по компаниям в Яндекс DataLens]


## Что уже реализовано

- исходный реестр: 10 573 юридических лица с ОКВЭД 41.20;
- нормализация ИНН, включая восстановление ведущих нулей;
- устойчивые HTTP-запросы через `requests.Session`, таймауты и повторные попытки;
- сбор структурированной отчётности БФО за 2021–2025 годы;
- расчёт EBIT по формуле `прибыль до налогообложения + проценты к уплате − проценты к получению`;
- подготовка источников и структуры интерактивного дашборда в Яндекс DataLens;
- статическая карта топ-500, построенная через GeoPandas;
- экспериментальное извлечение амортизации из PDF и OCR в `functions.py`.

## Важное ограничение EBITDA

В структурированной отчётности БФО амортизация не выделена отдельным показателем. Поэтому EBIT можно рассчитать массово, а полноценный EBITDA требует извлечения амортизации из пояснений к отчётности. PDF-парсер уже работает на части форматов, но пока не даёт полного покрытия всего реестра. Пропущенную амортизацию нельзя приравнивать к нулю так как такие наблюдения должны оставаться без EBITDA и иметь статус ручной проверки.

## Файлы

- `fast_pipeline.py` — возобновляемый массовый сбор структурированных данных;
- `analyze_results.py` — проверка, расчёт роста, рейтинги, Excel и PNG-графики;
- `geocode_top500.py` — возобновляемое геокодирование и интерактивная карта;
- `geopandas_map.py` — карта топ-500 через `GeoDataFrame` и экспорт GeoJSON;
- `prepare_datalens.py` — подготовка компактных таблиц для Яндекс DataLens;
- `run_ebitda_batch.py` — возобновляемый запуск PDF/OCR-парсера для топ-компаний;
- `functions.py` — прототип расчёта EBITDA с извлечением амортизации из PDF/OCR;
- `construction_companies.csv` — входной реестр компаний;
- `results/` — итоговые таблицы, графики и Excel-книга.

## Запуск

python fast_pipeline.py --limit 0
python analyze_results.py
python geocode_top500.py --limit 0
python prepare_datalens.py
python geopandas_map.py
python run_ebitda_batch.py --limit 0

Сбор сохраняет результат после каждой компании. Повторный запуск продолжает работу с места остановки. Значения финансовой отчётности БФО хранятся в тысячах рублей.

## Текущее покрытие

Полный реестр обработан: финансовые данные найдены для 10 480 компаний, ещё 93 компании отсутствуют в БФО. В итоговой карте присутствуют все 500 компаний: если адрес здания не находился, использовалась резервная привязка к городу или региону.

Главный незавершённый участок — массовая EBITDA. Для её расширения нужно продолжить возобновляемый запуск `run_ebitda_batch.py`; результаты с необычно большой амортизацией должны проходить ручную проверку и не считаются подтверждёнными.

## Интерактивный дашборд в Яндекс DataLens

Для дашборда подготовлены отдельные источники, чтобы не загружать в сервис всю техническую Excel-книгу:

- `results/datalens_financials.csv` — 48 066 наблюдений компания–год для KPI,
  динамики, распределений и фильтров;
- `results/datalens_top500_map.csv` — 500 компаний с координатами и финансовыми
  показателями для точечной карты;
- `results/datalens_regions.csv` — агрегаты по 88 регионам;
- `results/datalens_sources.xlsx` — те же источники в одной книге;
- `results/top_500_geopandas.png` — готовая статическая карта для отчёта;
- `results/top_500_geopandas.geojson` — пространственный слой точек.

Рекомендуемая первая страница дашборда:

1. Фильтры: год, регион и категория МСП.
2. KPI: количество компаний, суммарная выручка, медианная чистая прибыль,
   доля прибыльных компаний и медианный рост прибыли.
3. Линейный график выручки и чистой прибыли по годам.
4. Диаграмма рассеяния «выручка — чистая прибыль».
5. Топ-20 компаний по чистой прибыли.
6. Региональный рейтинг по медианному росту и доле прибыльных компаний.
7. Точечная карта топ-500: размер — чистая прибыль, цвет — категория МСП.

На карте DataLens геоточка создаётся вычисляемым полем `GEOPOINT([Широта], [Долгота])`. Финансовые показатели в источниках дашборда
переведены в миллионы рублей; исходные данные БФО остаются в тысячах рублей.

## Проверяемые гипотезы

## Очень важный момент!!!
Гипотезы сформулированы как связи в наблюдательных данных, но не как доказанные причинно-следственные эффекты. Подробная таблица сохранена в `results/hypotheses.csv`. Все сугубо мои предположения в рамках учебного задания.

1. **Средние предприятия имеют более высокую типичную чистую прибыль, чем малые.**
   Предварительно поддерживается: медиана за 2025 год составляет 4,4 млн руб. у
   средних предприятий и 1,5 млн руб. у малых.
2. **Более высокая выручка связана с более высокой чистой прибылью.**
   Поддерживается: ранговая корреляция Спирмена за 2025 год равна 0,562.
3. **Положительный EBIT связан с большей вероятностью получить чистую прибыль.**
   Поддерживается: прибыльны 96,3% компаний с положительным EBIT против 30,2%
   компаний с неположительным EBIT.
4. **EBIT и чистая прибыль движутся в одном направлении.**
   Поддерживается сильной ранговой связью: коэффициент Спирмена равен 0,852.

Эти результаты описывают выборку компаний, для которых найдена отчётность БФО. Перед причинными выводами необходимы проверка устойчивости по годам, контроль размера компании и региона, а также анализ пропусков и выбросов.
